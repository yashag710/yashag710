## 👋 About me

I'm a final-year CS student at **IIIT Kota**. I got into backend work because of the problems that show up *after* something works: a queue that starts choking, a request that suddenly gets blocked, a service that's fine until real traffic arrives. Fixing those is the part I enjoy most.

- 🧪 **Right now:** I'm an SDE Intern at **ScalerAI Labs**, where I help build the training and evaluation pipelines for RL agents and serve the trained policies through FastAPI.
- 🌱 **Still learning:** Kafka, deeper FastAPI, CI/CD, cloud deployments and system design.
- 🤝 **Happy to team up on:** DevOps-style projects like CI/CD, containers and scaling things properly.
- 💬 **Ask me about:** backend work, AI apps, React and Next.js.

| **[Vbloc: YouTube Summarizer](https://github.com/yashag710/Youtube-summarizer)** ✅ *finished* | I built this to turn long YouTube videos into clear summaries and study notes (20+ notes in under 60 seconds).
